# Coffee Brew Log

## Description

Coffee Brew Log is a full-stack web application that allows users to
create, view, filter, edit and delete coffee brew records.

The application was built as part of the Full-stack Developer Bootcamp
assessment.

## Features

- Create a brew entry
- View the brew log
- Filter brews by brew method
- Edit a brew entry
- Delete a brew entry
- Frontend form validation
- Backend validation
- Responsive user interface

## Tech Stack
