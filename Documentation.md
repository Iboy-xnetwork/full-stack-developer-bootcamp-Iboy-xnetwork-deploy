# Coffee Brew Log

## Description

A full-stack application that allows users to create, view, edit and delete coffee brew records.

## Tech Stack

Frontend:
- React
- Tailwind CSS

Backend:
- Node.js
- Express

Database:
- PostgreSQL

ORM:
- Prisma

## Setup Instructions

### Frontend

npm install
npm run dev

### Backend

npm install
npm run dev

## Environment Variables

Create a .env file using .env.example
